# 数据库字段与物理量词典

本词典说明发布规范及示例所涉及的字段。`—` 表示无量纲；`deg` 为角度；`m`、`K`、`Pa` 分别为米、开尔文、帕。不存在或不适用的量留空。具体 MISES 输出的物理背景见《MISES 输出量与解析说明》。

## 1. 标识、几何和采样

| 字段 | 单位 | 定义 |
|---|---|---|
| `design_id` | — | 设计的稳定唯一标识，不编码物理量含义。 |
| `case_id` | — | 求解工况的稳定唯一标识；工况由设计与一组边界条件确定。 |
| `point_id` | — | 气动点的稳定唯一标识。 |
| `parameterization` | — | 几何参数化方法名称；若直接提供坐标，记录 `coordinates` 等明确值。 |
| `geometry_file` | 路径 | 可重建叶型/叶栅的几何数据位置。 |
| `valid` | 布尔 | 几何是否通过所定义的自交、厚度、流道等检查。 |
| `chord_m` | m | 设计在物理空间中的弦长；不得用计算平面无量纲弦长替代。 |
| `solidity` | — | 稠度，弦长与栅距之比 `c/s`；需说明弦长与栅距使用同一坐标约定。 |
| `mises_reference_length_m` | m | MISES 无量纲边界层厚度等量的参考长度 `Lref`。 |
| `x_t`, `x_c` | — | 最大厚度、最大弯度位置相对弦长的坐标。 |
| `t_max_over_c`, `camber_max_over_c` | — | 最大厚度、最大弯度除以弦长。 |
| `betac_le_deg`, `betac_te_deg` | deg | 弯度线前缘、后缘切线方向角；需附角度正方向。 |
| `gamma_deg` | deg | 叶型安装角；需附坐标系和正方向。 |
| `le_axis_ratio` | — | 参数化前缘椭圆长短轴比，适用时填写。 |
| `te_thickness_over_c` | — | 尾缘厚度与弦长之比。 |
| `section_id`, `span_fraction` | — | 可选截面标识、展向相对位置，后者通常在 0–1。 |
| `sampling_method`, `sample_index` | — | 可选采样策略和样本序号；序号不作为主键。 |

## 2. 边界条件和工况状态

| 字段 | 单位 | 定义 |
|---|---|---|
| `M1`, `Minl` | — | `M1` 是工况施加并验证的入口 Mach；`Minl` 是某气动点的求解输出入口 Mach。 |
| `Mout` | — | 求解输出的出口 Mach。 |
| `mach_control_mode` | 类别 | Mach 控制方式，例如 `fixed` 或由其他约束确定；应与实际边界条件一致。 |
| `Re` | — | Reynolds 数 `ρ W L/μ`；必须注明速度和长度基准，示例为入口相对速度与设计物理弦长。 |
| `Re_million` | 10⁶ | MISES polar 输出的 Reynolds 数除以一百万；不自动等同于 `Re/10⁶`，需核对长度基准。 |
| `inlet_total_temperature_K`, `inlet_static_temperature_K` | K | 入口总温、静温；旋转叶栅需注明绝对或相对坐标系。 |
| `inlet_total_pressure_Pa` | Pa | 入口总压；旋转叶栅需注明坐标系。 |
| `Tu_percent` | % | 入口湍流强度百分数；数值 `0.07` 表示 0.07%，不是 7%。 |
| `tsrat` | — | 热力学参数；所述转子流程取 `T_ref/Tt,rel`，其中 `T_ref=110 K`。其他流程需声明定义。 |
| `stream_rotrel` | — | MISES stream 输入的相对旋转参数 `ROTREL`；确切无量纲化由所用流道定义给出。 |
| `inlet_angle_mode` | 类别 | `single` 为单点，`sweep` 为入流角扫掠。 |
| `polar_center_mode`, `polar_center_beta_deg` | 类别、deg | 扫掠中心定义及其入流角；仅扫掠时使用。 |
| `outlet_constraint_released` | 类别 | 为满足入口角或固定 Mach 控制而释放的出口约束标识；未释放则为空。 |
| `status`, `message` | 类别、文本 | 工况收敛/失败状态和原因，失败不应删除。 |
| `has_characteristic` | 布尔 | 是否成功提取至少一个特征点；不等于扫掠窗口完整。 |
| `run_result` | 路径 | 求解结果及追溯信息的位置，推荐相对路径。 |

## 3. 气流角度、损失和扩散

| 字段 | 单位 | 定义 |
|---|---|---|
| `Sinl`, `Sout` | — | 入、出口流角正切值：`tan β1`、`tan β2`。 |
| `beta1_deg`, `beta2_deg` | deg | `atan(Sinl)`、`atan(Sout)` 转成度；具体角度象限受求解器约定限制。 |
| `incidence_deg` | deg | 入口流角减几何入口金属角，按规定角度区间归一。 |
| `turning_deg` | deg | 入出口流角之差 `β1−β2`。 |
| `Pinl_Po1`, `Pout_Po1` | — | 入口/出口静压相对入口总压 `Po1` 的比值。 |
| `omega`, `omega_v` | — | polar 的总损失系数、粘性损失分量；精确压力差和速度头定义须由求解器版本说明。 |
| `DF` | — | polar 输出的扩散因子；精确公式取决于输出程序定义。 |
| `Deq` | — | 扩散比，输出数值约为 `Wmax/W2`；受 `Wmax` 取值质量限制。 |
| `D_velocity_term` | — | `1−W2/W1`。 |
| `D_loading_signed` | — | `DF−D_velocity_term`，用于判断当前规则下的载荷方向。 |
| `cl` | — | polar 输出的叶型升力系数；参考尺度与符号由求解器版本定义。 |
| `Phi`, `Psi` | — | polar 输出的流量、负荷系数；具体参考速度和符号由流道模型定义。 |

## 4. 速度、边界层与尾迹

| 字段 | 单位 | 定义 |
|---|---|---|
| `W1`, `W2` | 求解器速度单位 | 入口、出口相对速度；米每秒换算需速度基准。 |
| `Wmax` | 同上 | 扩展 polar 的单一表面最大速度输出，选择位置尚未完全核查。 |
| `Wmax_top`, `Wmax_bottom` | 同上 | 两侧表面的最大速度；最大值搜索范围尚需版本说明。 |
| `W_te_top`, `W_te_bottom` | 同上 | 上、下表面尾缘测量站的速度。 |
| `Wmax_over_W1` | — | `Wmax/W1`。 |
| `Wmax_physical_suction` | 同上 | 根据载荷方向选定一侧的最大速度；选择规则不保证极值位置正确。 |
| `Wmax_envelope_audit` | 同上 | `max(Wmax_top,Wmax_bottom)`，仅用于审计。 |
| `Deq_physical`, `Deq_envelope_audit` | — | 分别为上述两种速度除以 `W2`。 |
| `wmax_quality_status` | 类别 | 最大速度选择和位置的核查状态。 |
| `theta_te_top/bottom` | `Lref` 的倍数 | 上/下表面尾缘动量厚度 `θ`；物理定义为 `∫(ρu/ρ_eu_e)(1−u/u_e)dn`。 |
| `delta_star_te_top/bottom` | `Lref` 的倍数 | 上/下表面尾缘位移厚度 `δ* = ∫[1−ρu/(ρ_eu_e)]dn`。 |
| `H_te_top/bottom` | — | 各侧尾缘形状因子 `δ*/θ`。 |
| `H_te_combined` | — | `(δ*_top+δ*_bottom)/(θ_top+θ_bottom)`。 |
| `theta_wake_exit`, `delta_star_wake_exit` | `Lref` 的倍数 | 尾迹出口动量、位移厚度；不是尾缘两侧值的直接和。 |
| `H_wake_exit` | — | 尾迹出口 `δ*/θ`。 |
| `*_m`, `*_over_b2b_chord` | m、— | 厚度换算：`q_m=q_raw Lref`，`q/c=q_raw Lref/chord_m`。 |
| `theta_te_measurement_station`, `wake_exit_measurement_station` | 类别 | 测量站定义，例如表面尾缘和指定尾迹出口站。 |
| `wake_exit_data_status` | 类别 | 尾迹出口数据可用性；缺失时不补造数值。 |

## 5. 转捩、分离、特征点和筛选

| 字段 | 单位 | 定义 |
|---|---|---|
| `Xtr_top/bottom` | — | 上/下表面转捩位置，沿所采用表面坐标归一；坐标约定须说明。 |
| `separation_fraction_top/bottom` | — | 分离位置相关输出；`-1` 视为不可用哨兵，不视作物理位置。正值的归一化定义需随程序版本提供。 |
| `Cf_min_top/bottom` | — | 各侧最小摩擦系数；负值可能有物理意义，不能直接视为缺失。 |
| `branch` | 类别 | 扫掠分支，如入流角向小/向大方向。 |
| `point_type` | 类别 | `minimum_loss`、`double_loss_left`、`double_loss_right` 等特征点类别。 |
| `interpolated` | 布尔 | 特征点是否由邻近气动点插值得到。 |
| `double_loss_target` | 同损失系数 | 双倍损失目标；若定义系数为 2，则为 `2 × minimum_loss omega`。 |
| `double_loss_status` | 类别 | `reached` 表示找到交点；`boundary_limited` 表示扫描边界仍未达到。 |
| `physical_suction_side`, `reverse_loaded` | 类别、布尔 | 根据载荷方向选定的物理吸力面及是否反载。 |
| `classic_positive_loading_eligible` | 布尔 | 是否满足所选经典正载关联式的适用条件。 |

## 6. 旧字段的解释（仅用于数据转换）

旧 `chord` 是 MISES 计算平面的几何弦长，不是米；`design_b2b_chord_m` 是物理弦长。`b2b_chord_m_per_mises_plane_unit = baseline_b2b_chord_m / baseline_mises_plane_chord`，用于平面单位与物理米数对应；`input_length_unit_to_m` 是原始输入长度单位到米的比例，两者不是同一换算。旧 `installation_angle_deg` 对应规范 `gamma_deg`。旧 `gamma_le_deg`、`alpha_te_deg`、`beta_te_deg` 是参数化形状量，不能仅改列名得到 `betac_le_deg`、`betac_te_deg`。旧 `requested_M1` 是调度值，`Minl_requested_in_ises` 是写入值，`reference_M1_for_Re` 是 Reynolds 缩放基准；发布核心工况使用最终施加并核实的 `M1`。
